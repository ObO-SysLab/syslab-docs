### AI로 해결한 문제

채점

| 문제 | AI가 한 일 | 팀이 한 일 | 결과 |
| --- | --- | --- | --- |
| 간편 모드 코딩 문제가 모두 채점 실패 | 채점기 로그를 추적해 OBO 실행 파일의 줄바꿈이 바뀌어 무결성 검사에 걸린 것을 찾고, 수정본과 재배포 순서를 만들었다 | 재배포 승인, 오답·정답 제출로 확인 | 다시 정상 채점 |
| 제출 후 결과까지 92~99초 | 컨테이너 작업으로 돌던 채점 조정 단계를 Lambda로 옮기는 코드를 작성했다 | 구조 변경 승인, 운영에서 시간 측정 | 42~46초 |


실습 환경

| 문제 | AI가 한 일 | 팀이 한 일 | 결과 |
| --- | --- | --- | --- |
| 실습 문제에서 막아야 할 명령도 실행됨 | 전용 계정, 허용 목록 밖 실행 파일의 권한 제거, 임시 폴더 실행 금지로 제한을 구현하고 배포 순서를 정리했다 | 제한 방식과 포함 범위 결정, 운영 시험 | 운영 시험 문제에서 거부 동작 확인 |
| 터미널 크기가 맞지 않고, 환경 빌드가 실패해도 원인이 안 보임 | 크기 전달, 실패 원인 표시, 다시 빌드 기능을 추가했다 | 추가 항목 선택 | 반영 |

운영·인프라

| 문제 | AI가 한 일 | 팀이 한 일 | 결과 |
| --- | --- | --- | --- |
| 운영 서버가 저장소 코드와 같은지 알 수 없음 | 로컬 코드와 AWS 배포본, EC2 내부를 대조해 차이를 문서로 정리했다 | 조치 순서 결정 | 수정 목록과 이슈별 커밋 정리 |
| 없는 API 주소가 404 대신 첫 화면으로 응답 | CloudFront 오류 응답 설정이 원인임을 찾아 API와 페이지의 응답을 나눴다 | 변경 승인 | API는 404, 페이지는 404 화면 |
| 공개 저장소에 비밀 값이 남았는지 알 수 없음 | 전체 기록과 PR 참조까지 검색했다 | 결과 검토, 쓰지 않는 키 삭제 결정 | 자격 증명 커밋 0건 |

웹 화면

| 문제 | AI가 한 일 | 팀이 한 일 | 결과 |
| --- | --- | --- | --- |
| OBO 시각화 화면에 문장이 많아 읽기 어려움 | 모듈마다 그림과 하단 설명을 나누고 실제 화면 캡처로 비교했다 | 방향과 초기 피드백. 2026-11-08 이후 세부 디자인은 AI에 맡기고 결과만 확인 | 반영 |
| 글자 대비, 제목 단계, 어색한 문구 | 정적 검사 결과를 받아 수정했다 | 바꿀 항목 선택 | 반영 |
| 일부 페이지가 로딩을 끝내지 못함 | 실패 응답 본문을 닫지 않아 요청이 남는 문제를 고쳤다 | 확인 | 해결 |

그 밖에 라이트 테마, 알림, 상점, 계정 탈퇴, 문제 아이콘과 캐릭터 움직임도 AI로 구현했다. 포인트 정책 같은 규칙은 팀이 정했다.

문제와 문서

| 작업 | AI가 한 일 | 팀이 한 일 |
